# Referências técnicas

Este registro identifica fontes técnicas consultadas para implementar e documentar o projeto. Referência não significa incorporação de código ou concessão de licença sobre a fonte.

- [FIDO Alliance — Client to Authenticator Protocol (CTAP)](https://fidoalliance.org/specifications/): especificações para autenticadores FIDO.
- [Yubico python-fido2](https://github.com/Yubico/python-fido2): biblioteca Python e exemplos de integração FIDO2.
- [NIST SP 800-38D](https://csrc.nist.gov/pubs/sp/800/38/d/final): Galois/Counter Mode (GCM).
- [RFC 5869](https://www.rfc-editor.org/rfc/rfc5869): HKDF.
- [RFC 8878](https://www.rfc-editor.org/rfc/rfc8878): Zstandard.
- [Astro](https://astro.build/) e [Starlight](https://starlight.astro.build/): ferramentas utilizadas para gerar o site e a documentação.
- [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0.html): licença do código original do projeto.

Para dependências efetivamente instaladas e suas versões, consulte o inventário de software e os avisos de terceiros no repositório.
