# Teuzin Vault

O Teuzin Vault é um aplicativo desktop experimental para compactar e proteger arquivos localmente, com criptografia autenticada, autenticador FIDO2 e recuperação independente.

> **Estado experimental:** o projeto ainda não passou por auditoria independente. Não utilize como única cópia de arquivos importantes.

## Estado atual

- Núcleo criptográfico e contêiner TVLT V1 preliminar.
- FIDO2 com verificação do usuário obrigatória no fluxo validado em hardware.
- Migração de slot FIDO2 preservando o slot de recuperação.
- Interface desktop com restauração de arquivos individuais.
- Criação de cofres pela interface, pastas e distribuição ainda em desenvolvimento.
